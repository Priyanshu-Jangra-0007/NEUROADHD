## 1. Executive Objective & Strategic Summary

The technical investigations in Phase 2D, 2E, and 2F established that while the staged NIAK intermediate matrices are mathematically capable of deriving rigid-body kinematics, relying on them introduces cross-optimizer divergences and a $\pm 1$ frame dummy-scan alignment uncertainty.

To guarantee **100% protocol fidelity** with Section 4 of the publicly registered OSF protocol ([PREREGISTRATION.md](PREREGISTRATION.md)), Study 2 will recover the authentic, Athena-native **AFNI `rp_*.1D` motion parameter files** directly generated during the original Athena preprocessing stream.

## 2. Technical Specification of Target Athena Motion Traces

From the official upstream Athena preprocessing scripts (`preprocessed-connectomes-project/adhd200_athena_scripts`):

### 2.1. File Naming & Path Architecture
- **Naming Pattern:** `rp_${subjid}_${sid}_${rid}.1D`  
  (e.g., `rp_<ID>_session_1_rest_1.1D` or `rp_<ID>_session_1_rest_1.1D`)
- **Generation Directive:**
  ```bash
  coreg_base=rm_da${bold_file}'[0]'
  3dvolreg -Fourier -prefix rm_r${prev_step##rm_} -base ${coreg_base} \
           -1Dfile rp_${bold_file%%.nii.gz}.1D ${prev_step}
  ```
- **Provenance Proof:** Confirmed generated by AFNI `3dvolreg` (Fourier interpolation) against volume 0 of the post-dummy-drop functional run.

### 2.2. Dimensionality, Parameter Order & Physical Units
From the AFNI `3dDeconvolve` nuisance regression specification (`preproc.sh` lines 278–283):
- **Column Count:** Exactly 6 numerical columns:
  - Column 0: `roll` (rotation about A-P axis / coronal plane) — **Degrees**
  - Column 1: `pitch` (rotation about R-L axis / sagittal plane) — **Degrees**
  - Column 2: `yaw` (rotation about I-S axis / axial plane) — **Degrees**
  - Column 3: `dS` (displacement Superior) — **Millimeters (mm)**
  - Column 4: `dL` (displacement Left) — **Millimeters (mm)**
  - Column 5: `dP` (displacement Posterior) — **Millimeters (mm)**
- **Row Count ($T_{\text{CC200}}$):** Because `3dvolreg` was executed on truncated volumes (after `3dcalc` removed initial dummy scans), each file has row count matching the CC200 BOLD time courses:
  - **KKI:** 121 or 149 rows
  - **NeuroIMAGE:** 258 rows
  - **OHSU:** 75 or 73 rows
  - **Peking:** 233 rows
- **Temporal Alignment:** Row 1 corresponds to volume 0 of the retained BOLD series (the reference volume, where rotations and translations equal 0.0000). Successive volume-to-volume differencing produces **zero boundary ambiguity**.

### 5.1. File Verification Criteria
Before computing Framewise Displacement, each recovered trace must satisfy:
1. **Filename Match:** Exactly matches `rp_<ID>_session_1_rest_1.1D` for each of the 404 development participants.
2. **Column Structure:** Exactly 6 floating-point values per row.
3. **Row Count Match:** Exactly matches the line count of the corresponding CC200 BOLD time course in `ADHD200_CC200_TCs_filtfix.tar.gz`.
4. **Physical Sanity:** Translations within $[-20, +20]\text{ mm}$; rotations within $[-30^\circ, +30^\circ]$.
