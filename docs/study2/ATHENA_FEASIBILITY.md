## 3. Discarding the Cloud Pilot & Recommended Path

### 3.1. Re-evaluation of Cloud Reprocessing
The proposed AWS cloud pilot (reprocessing raw DICOM/NIfTI scans using C-PAC on EC2) is **permanently dropped from the recommended path**:
* **Scientific Disadvantage:** Running raw fMRI preprocessing introduces confounding degrees of freedom (slice-timing correction options, boundary-based registration variations, arbitrary motion scrubbing thresholds) without resolving the fundamental sample size limits.
* **Financial & Engineering Overhead:** Cloud orchestration introduces substantial failure points (Docker image drift, memory paging bottlenecks, dangling EBS volumes, AWS cost runaway risks).

### 3.2. Approved Recommended Path
The sole approved path for Study 2 is **Option 1: Pre-computed Athena Derivatives from NITRC**:
1. Zero compute cost (\$0.00 cloud spend).
2. Direct download of public, peer-reviewed AFNI/FSL derivative time series.
3. Evaluated strictly using `scripts/athena_inspect.py` (read-only, count-only audit) before any model fitting.
4. Frozen execution of the pre-registered Study 2 protocol documented in `docs/study2/PREREGISTRATION.md`.
