100% Executed. All 6 base classifiers (Logistic Regression, Linear SVM, RBF SVM, Random Forest, Extra Trees, XGBoost) plus 3 ensemble models were fully executed across all 7 runs.

Q: What leakage/overfitting concerns exist?

• Data Leakage: NONE. Preprocessing was fit strictly on the training set (114 subjects).
• Overfitting: HIGH. Training ROC-AUC reached >0.99 for tree models, while validation ROC-AUC dropped to 0.68–0.73 and Peking_2 test ROC-AUC dropped to 0.63.
• Class Imbalance Collapse: Models without class weighting defaulted to predicting the majority class (Control), producing 0% ADHD recall on validation for 4 out of 6 models.

6. Recommended Next Experiments
  1. Class-Weight Balancing: Enable class_weight="balanced" or scale_pos_weight (or SMOTE) to fix the 0% validation recall issue for minority ADHD class.
  2. Feature Selection Grid Search: Test K values in [20, 50, 100, 200, 500] and explore L1 (Lasso) / ElasticNet feature selection instead of pure ANOVA F-test.
  3. Strong Regularization: Restrict max_depth to 2-3 for tree models and test smaller C values (0.001 - 0.05) for SVM and Logistic Regression to combat high-variance overfitting.
  4. Cross-Validation Scheme: Implement Leave-One-Site-Out Cross Validation (LOSO-CV) across all training sites to improve site generalization before Peking_2 testing.
