02 Launch Interactive Web Application

Run backend and frontend in two separate terminal windows:

# Terminal 1 (FastAPI Backend):
cd /Users/apple/Documents/Codex/2026-09-29/down/NeuroADHD_ModelDashboard/backend
python -m uvicorn server:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2 (React 18 Frontend):
cd /Users/apple/Documents/Codex/2026-09-29/down/NeuroADHD_ModelDashboard/frontend

npm run dev
# Access Dashboard: http://localhost:5173
